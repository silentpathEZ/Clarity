# Clarity

An interactive web messenger bridging the communication gap between hearing and Deaf or hard-of-hearing users through real-time sign language translation.

## About the Project

Clarity is built to make digital communication accessible for everyone. Using computer vision and 3D rendering, the platform instantly translates sign language into text and synthesized speech. At the same time, it converts spoken language into natural 3D hand gestures.

The interface features a clean, dark glassmorphism design and is fully optimized for both desktop and mobile devices to ensure a smooth experience anywhere.

## Key Features

* Real-time 3D hand tracking for accurate and smooth gesture animation.
* Dual user modes to easily switch between a hearing interface and a sign language interface.
* Interactive dictionary to preview and learn basic signs and fingerspelling.
* Live transcript that automatically logs the conversation so you never lose context.
* Adaptive streaming quality that adjusts to your internet connection for stable calls.
* Built-in network latency and AI status monitors directly in the call interface.
* Fully responsive design optimized for smartphones, tablets, and desktops.
